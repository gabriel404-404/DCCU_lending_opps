# LGE P3 baseline

Every CSV in `data/processed/lge/` (here `processed/`) and `outputs/lge/` (here `outputs/`) as of
productize P3 (2026-11-01), saved with `check_baseline.py --save p3` after the user approved LGE's
numbers. Names are current, so no translation is needed. `src/check_baseline.py` compares each LGE
run against these files. Do not edit them; save a new version for an intended change.
